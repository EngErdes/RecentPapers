## 📝 要約

ものにタッチしているとき、いないとき、指を動かしているいるとき、いないときで、加速度センサーから得られる信号の波形が明確に違う。

ものにタッチして指を動かしているときには、特定の方向にだけ加速度センサーの波形が反応している。
