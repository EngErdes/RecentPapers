## 📝 要約

チュニジアにおける把握が困難な非公式な公共交通機関の実態を、統計的に推計するための新しい手法を提案しています。特に社会的な危機下での不完全なデータを扱うため、制御工学の手法であるカルマンフィルタを適用し、精度の高い推定を実現しました。

## ❓ どんな問題に取り組んだか

非公式な交通セクターは公的な統計に現れにくく、正確な需要や供給の把握が極めて困難です。特に経済的・社会的な危機の最中では、既存の静的な統計調査ではデータのノイズや欠落に対応できず、有効な政策立案が妨げられていました。

## ✨ 何が新しい？何がすごい？（新規性）

従来、経済学では静的な推計モデルが一般的でしたが、本研究は制御理論で用いられる「カルマンフィルタ」を交通経済学に応用しました。これにより、非公式輸送という「観測不可能な状態」を、他の観測可能な指標から動的に追跡・予測できるようにした点が、これまでの先行研究にはない独自の貢献です。

## 🎓 大学1年生向けの解説

チュニジアでは、国の許可を得ずに営業しているタクシーやバスが重要な移動手段になっていますが、正確な数は誰にもわかっていません。この研究は、ロボットの姿勢制御などに使われる数学的なテクニック（カルマンフィルタ）を使い、不正確なデータから「本当の交通量」を割り出す方法を開発しました。これによって、社会が混乱している時期でも、人々の移動の実態を科学的に捉えることが可能になります。
